# Project Statement

## Problem Statement :

Students often have many small expenses during the month, and it can become difficult to keep track of them. Because of this, they may not know how much they have already spent or how much of their budget is left.

I created this project to provide a simple way to record expenses and keep track of monthly spending using Python.

## Scope :

This project is a command-line expense and budget tracker. It allows the user to add, view and delete expenses, set a monthly budget, check the remaining budget and see a spending report.

The project is mainly focused on basic expense management and does not include online payments or bank account connections.

## Target Users :

The main users of this project are students who want a simple way to keep track of their daily expenses and monthly budget.

## High-Level Features :

### 1. Expense Management :

* Add new expense
* View saved expenses
* Delete an expense

### 2. Budget Management :

* Set a monthly budget
* Check total spending
* Check the remaining budget

### 3. Spending Report :

* Calculate total spending
* Show spending category-wise

### 4. Data Storage :

* Save expenses in a JSON file
* Load saved expenses when the program starts
